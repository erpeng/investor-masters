## 这篇材料要求回填哪些投资人页

[查克·阿克雷](/investor-masters/investors/chuck-akre/)：1988—2019 的材料用于说明方法为什么形成；2020 以后资料用于划清传承边界。外部回报证据进入简介验证卡，不能取代一手方法。行为与解释分层。

[Bandag](/investor-masters/companies/bandag/)、[American List](/investor-masters/companies/american-list/)、[International Speedway](/investor-masters/companies/international-speedway/)、[American Tower](/investor-masters/companies/american-tower/)。

## 这篇材料要求新建或更新哪些概念 / 对话 / 机构页

再投资跑道把「回报率、可投比例、持续期」分开；两篇既有对话分别检验好生意是否有资本去路，以及持有纪律何时需要让位于估值更新。机构页保留与个人不同的资金和决策约束。
