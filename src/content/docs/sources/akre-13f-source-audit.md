- Q3全部21个证券身份包含20项非期权与1项CRM CALL；期权标的名义值不是权利金。

- 2024Q1 NEW HOLDINGS补报含20项与原表完全相同的证券，仅补SOPH，重复项去重；不将整表再次相加。
- 同CUSIP类别拼写按原始表逐项归一；原文及归一依据保留在快照。
- 当前候选使用2026-11-16行情；缺失保留N/A。同日报价复用保留旧快照哈希与本次失败记录。
