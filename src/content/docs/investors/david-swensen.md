> **一句话定义**  
> 把大学 endowment 的长钱结构变成资产配置优势的人。

**所属机构**: [Yale Investments Office](/investor-masters/institutions/yale-investments-office/)  
**年化收益率**: 未公开  
**代表性持仓**: Yale Endowment、另类资产、外部管理人网络  
**核心方法**: 耶鲁模式 / 长钱 / 流动性预算 / manager selection

## 简介

大卫·史文森最值得单独读的地方，是他把“投资大师”这个词从选股高手扩展到了 `长钱制度设计者`。他不是靠讲出某只股票的非共识观点出名，而是把 Yale Endowment 的负债端、治理、流动性承受能力、外部管理人网络和大学使命连成了一套投资系统。

如果 Buffett 问的是“哪家公司值得拥有”，Swensen 问的是“一个永续机构应该如何把时间结构变成投资优势”。这是完全不同的游戏。

验证卡：Yale News 官方口径显示，Swensen 自 `1985` 年起管理 Yale Endowment，35 年年化约 `13.1%`，高于 Cambridge Associates endowment universe 平均值约 `3.4pct`，高于 60/40 股票债券组合约 `4.3pct`。依据：[Yale News｜David Swensen讣闻与35年业绩](/investor-masters/sources/source-84/)。

## 来时路

Swensen 的关键身份不是普通基金经理，而是 Yale Investments Office 的长期 CIO。他的投资对象不是单一基金净值曲线，而是一所大学的长期使命：今天要支持教学科研，未来也要保护后代学生和教师的资源。

这条路径决定了他的优势来源：他管理的是长钱，不是短钱；他面对的是跨代责任，不是季度排名；他真正要优化的是长期实际购买力和机构稳定性，而不是短期相对收益。

Yale Model 的形成，就是把这些约束翻译成投资动作：降低传统股票债券组合依赖，增加另类资产和非流动资产配置，寻找优秀外部管理人，并通过长期伙伴关系拿到普通资本拿不到的机会。

## 人物分析

**鲜活信号**

- `反复出现的词`：endowment、long term、manager、partners、illiquidity、governance、mission。
- `最爱把问题压回哪一层`：压回机构的时间结构和能力结构，而不是单个资产短期涨跌。
- `怎么处理不确定性`：用多资产、多 manager、长期治理和流动性规划承接，而不是靠短期择时。
- `怎么谈人`：他判断的“管理层”主要不是上市公司 CEO，而是外部投资管理人。
- `回答姿态`：不像交易员，也不像企业所有者，更像一位把投资嵌进大学制度的资本架构师。

**画像判断**

Swensen 的底层方法可以压成一句：`把长期负债端变成优势，再用极强 manager selection 把这种优势兑现。`

这句话有两个不可分割的部分。第一，长期资金能承受流动性折价和短期波动；第二，你必须真的有能力找到能兑现这种折价的管理人。少掉第二点，Yale Model 就会退化成“买一堆高费另类资产”。

所以 Swensen 不是“另类资产崇拜者”。他的真正贡献，是把资产配置、治理、流动性、外部伙伴和使命约束拼成一个系统。

## 失误、边界与失效条件

Swensen 这套方法最大的误用风险，是被机构机械复制。

它成立需要几个前提：

- 资金必须足够长，不能被短期赎回逼迫卖出。
- 治理必须稳定，不能因为一年落后就推翻策略。
- 必须有 manager access，能接触并判断真正优秀的外部管理人。
- 必须有流动性管理，不能把非流动性当成免费午餐。

离开这些条件，“耶鲁模式”很容易变成高费率、高复杂度、低透明度的资产堆叠。

## 对我有什么启发

Swensen 的启发是：投资优势不只来自研究某家公司，也来自你拥有什么样的时间结构。负债端、现金流需求、治理耐心和可承受波动，本身就是投资方法的一部分。

对个人投资者，最该迁移的不是配置一堆另类资产，而是先问：我的钱到底有多长？我真的能承受多久的不流动？我有什么 manager selection 或资产识别能力？如果没有，所谓“长期配置”只是漂亮词。

## 横向定位

**最像谁**

更接近 [尼科莱·坦根](/investor-masters/investors/nicolai-tangen/) 和 [霍华德·马克斯](/investor-masters/investors/howard-marks/)。

**最不像谁**

更不像 [吉姆·西蒙斯](/investor-masters/investors/jim-simons/) 和 [大卫·泰珀](/investor-masters/investors/david-tepper/)。

**关键差异**

他和 Tangen 都在管理超长期机构资本，但 Swensen 的核心在 endowment model 和 manager network，Tangen 更像主权基金治理、情报学和普遍所有者视角。和 Marks 相比，两人都重视风险和周期，但 Swensen 更从资产配置和流动性预算出发。
