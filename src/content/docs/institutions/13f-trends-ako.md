这页只做一件事：把 AKO Capital 从 `2023Q1` 到 `2026Q1` 的 13F 持仓变化按时间摊开，再用 AKO 的机构语言去解释：高质量公司、长期 ROIC、专业团队验证，以及用流程减少自我欺骗。读法重点不是追热点，而是看质量名单如何重排。

## 结论先行

- AKO 是质量投资机构，不是宏观交易组合。最新 Q1 2026 可见 13F 有 `27` 个持仓，前 5 大合计 `40.2%`，前 10 大合计 `66.2%`。
- Q1 2026 13F 总市值变化：从 `$6.57bn` 到 `$5.11bn`，下降 `-$1.46bn`（-22.2%）。粗拆：主动仓位变化 `-$0.89bn`，价格变化 `-$0.57bn`；主要由主动仓位变化拖累。
- Q1 2026 最值得抄的不是前十大本身，而是质量名单变化：`ALC` 显著加仓，`WAT / CSCO` 新进前十；`FLTR / MCO` 退出前十，`MMC / CPRT / MSFT / MCO` 等出现明显减仓。
- `医疗/生命科学与眼科`、`平台/软件/云`、`支付/金融基础设施`、`高质量消费/稀缺品牌`、`工业/模拟芯片/基础设施` 构成当前可见骨架；Q1 2026 这五组可见暴露合计约 `81.3%`。
- 按 AKO 的手法，`ALC` 和 `WAT` 是最近一季更像“质量名单强化”的信号；`CSCO` 需要观察是否连续留在前十；`FLTR / MCO` 的退出比小幅权重变化更值得复盘。

## 数据口径

- 数据来自 SEC 13F information table，窗口为 `2022Q4-2026Q1`；正文展示 `2023Q1-2026Q1`，`2022Q4` 只用于计算 `2023Q1` 主动变化。
- 主动变化沿用机构页口径：已有仓位按 `(本季股数 - 上季股数) × 上季隐含价格` 估算，新进按本季市值，清仓按上季市值负数。
- 13F 只覆盖美国公开股票多头及部分期权披露，不等于 AKO 的完整欧洲与全球股票组合。
- 对 AKO 这种质量投资机构，单季买卖不是交易信号本身；更重要的是一家公司是否进入质量名单、是否连续留在前十、是否被明显踢出核心圈。

## 三、用 AKO 的方法重新读

### 1. 抄 AKO，不是抄单季涨跌，而是抄质量名单变化

AKO 的优势来自长期研究和专业团队过滤。`ALC / WAT / ICE / V / RACE / GE / ADI` 这类公司进入或稳定在前排，说明它们更值得进入质量候选池；但真正能不能买，还要回到估值、ROIC、会计质量、管理层语言和渠道验证。

### 2. 新进前十比小幅权重变化更重要

Q1 2026 的 `WAT / CSCO` 新进前十，比 `AMZN` 权重上升更有信号。因为 `AMZN` 股数基本稳定时，权重变化可能只是价格和组合总市值影响；新进前十则更接近质量名单优先级变化。
