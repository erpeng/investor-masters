## 结论先行

- AKO 是质量投资机构，不是宏观交易组合。最新 Q2 2026 可见 13F 有 `22` 个持仓，前 5 大合计 `48.0%`，前 10 大合计 `75.8%`。
- Q2 2026 13F 总市值从 `$5.11bn` 降至 `$4.29bn`，下降 `-$0.82bn`（-16.0%）。机械粗拆为主动仓位变化 `-$1.14bn`、价格变化 `+$0.32bn`，说明上涨的市场价格掩盖了更大幅度的缩表。
- 最新季度最强的正向动作是 `SUNB` 股数 `+90.7%`、升至第二大仓，以及 `APD` 股数 `+137.1%`；同时 `BKNG / CRM / FLTR / MMC` 清仓，`WAT / ICE / ADI / AMZN / CSCO` 大幅减股。
- `ALC` 仍是第一大仓且股数 `+3.8%`，但组合真正的新信息不是“继续持有质量股”，而是 AKO 一边集中到 `ALC / SUNB`，一边系统性降低旧核心仓位。
- 按 AKO 的手法，当前最值得研究的是 `SUNB / APD` 的质量名单升级；`MSFT / ADI / AMZN / CSCO` 虽仍在前十，但都不是本季加仓信号。

## 数据口径

- 数据来自 SEC 13F information table，窗口为 `2022Q4-2026Q2`；正文展示 `2023Q1-2026Q2`，`2022Q4` 只用于计算 `2023Q1` 主动变化。
- 主动变化沿用机构页口径：已有仓位按 `(本季股数 - 上季股数) × 上季隐含价格` 估算，新进按本季市值，清仓按上季市值负数。
- 13F 只覆盖美国公开股票多头及部分期权披露，不等于 AKO 的完整欧洲与全球股票组合。
- 对 AKO 这种质量投资机构，单季买卖不是交易信号本身；更重要的是一家公司是否进入质量名单、是否连续留在前十、是否被明显踢出核心圈。

### 这条线怎么读

AKO 的 13F 不能只按“买了谁、卖了谁”读。它的公开方法强调质量模式、行业结构、法务会计、行为语言、渠道调研、数据科学和可持续性研究。也就是说，一家公司进入前十，更像是通过一套多团队过滤器后的质量名单信号。

Q2 2026 的特点是“集中与缩表同时发生”：`SUNB / APD` 明显加股，`ALC` 保持第一大；但 `BKNG / CRM / FLTR / MMC` 清仓，多个旧核心仓位被削减。更合适的读法不是 AKO 转向某个热门行业，而是它在质量池内部大幅提高机会成本门槛。

## 三、用 AKO 的方法重新读

### 1. 抄 AKO，不是抄单季涨跌，而是抄质量名单变化

AKO 的优势来自长期研究和专业团队过滤。`ALC / WAT / ICE / V / RACE / GE / ADI` 这类公司进入或稳定在前排，说明它们更值得进入质量候选池；但真正能不能买，还要回到估值、ROIC、会计质量、管理层语言和渠道验证。

### 2. 加股进入前十，比被动权重上升更重要

Q2 2026 的 `SUNB` 股数接近翻倍并升至第二大，比 `ALC` 因缩表而权重上升更有增量信息。`CP` 虽进入前十，但股数下降 11.7%，属于被动进入，不能和 `SUNB` 放在同一类。

### 3. 退出前十要当作反证线索

`WAT / ICE` 退出前十、`BKNG / CRM / FLTR / MMC` 清仓不等于公司变差，但对 AKO 这种质量机构，退出核心名单本身就是反证：是估值、增长质量、行业结构，还是相对机会更好？
