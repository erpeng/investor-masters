## 用 Coatue 的方法重新读

Coatue 的公开 13F 至少有三层含义。

第一，它不是静态科技多头。2023 年前排更多是 `NVDA / META / AMD / AMZN / MSFT / TSLA`，到 2026Q1 则变成 `TSM / GEV / LRCX / AMAT / AVGO / ETN / EQIX / ASML` 这些更靠资本开支、制造和实物基础设施的节点。

第二，Coatue 的公私一体网络最有价值的地方，不是让外部读者知道它“看好 AI”，而是帮它更早看到哪一层从叙事变成收入、订单、资本开支和供给瓶颈。13F 只能看到公开切片，但这个切片已经在验证 AI stack 的迁移。

第三，外部抄作业必须降噪：`GEV / CEG / AMAT / AVGO / GOOGL` 这类仓位的权重变化混有价格和组合缩表影响；真正更干净的新线索是 `EQIX / ASML` 新进、`TSM` 继续增股、`ETN / LRCX` 仍在前排。

### 反向复盘

- `ORCL / SNOW / ADBE / AMD / ARM / MRVL`：退出，说明 Coatue 在 Q1 从软件/一阶芯片扩散到电力、设备、先进制造和数据中心。
- `NVDA / MSFT / GOOGL`：股数下降但仍保留一定权重；这不是简单看空，而是平台/GPU beta 被更上游或更稀缺环节挤压 opportunity cost。
- `GEV / CEG`：仍在前十，但股数下降；读作“资产线仍重要”，不能写成 Q1 主动加仓。
- `LRCX / AMAT / AVGO`：设备和 ASIC/网络方向被验证，但如果 13F 后涨幅过大，应降级为趋势复盘或等待回撤。

## 继续观察

- `TSM / LRCX / AMAT / ASML` 是否继续证明先进制程和设备约束。
- `GEV / CEG / ETN / VRT / EQIX` 是否继续作为 AI 电力和数据中心基础设施篮子存在。
- `NVDA` 权重下降后，Coatue 是转向 `AVGO / TSM / LRCX / AMAT`，还是整体降低 AI beta。
- `CRWV / RDDT / APP` 这类 IPO 或新公开资产，是否成为 Coatue 私募网络向公开市场迁移的样本。

## 不能确认的部分

- 不能用 13F 推断 Coatue 私募组合、基金申赎、空头、现金和完整风险预算。
- 不能把 `TSM / GEV / CEG` 的出现简单写成“防御”或“AI”，必须放在电力、资本开支和供给瓶颈里读。
- 不能把权重上升等同于主动加仓；本页显著加减仓以股数/份额变化为准。
- 不能从季度末持仓推断季度内交易路径，也不能假设 13F 后仓位仍未变化。
