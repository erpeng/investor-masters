## 用 Coatue 的方法重新读

Coatue 的公开 13F 至少有三层含义。

第一，它不是静态科技多头。2023 年前排更多是 `NVDA / META / AMD / AMZN / MSFT / TSLA`，到 2026Q1 则变成 `TSM / GEV / LRCX / AMAT / AVGO / ETN / EQIX / ASML` 这些更靠资本开支、制造和实物基础设施的节点。

第二，Coatue 的公私一体网络最有价值的地方，不是让外部读者知道它“看好 AI”，而是帮它更早看到哪一层从叙事变成收入、订单、资本开支和供给瓶颈。13F 只能看到公开切片，但这个切片已经在验证 AI stack 的迁移。

第三，外部抄作业必须降噪：`GEV / CEG / AMAT / AVGO / GOOGL` 这类仓位的权重变化混有价格和组合缩表影响；真正更干净的新线索是 `EQIX / ASML` 新进、`TSM` 继续增股、`ETN / LRCX` 仍在前排。
