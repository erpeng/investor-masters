## 结论先行

- Appaloosa 不能按低换手质量组合读。更准确的读法是 `政策反应函数 + 高机动公开市场表达`：公司、行业、ETF 和 put/call 都是同一张风险地图里的零件。
- 最新 Q2 2026 13F 总市值从 `$5.93bn` 升至 `$7.73bn`，增加 `$1.79bn`（+30.2%）；粗拆主动变化 `+$0.11bn`、价格变化 `+$1.68bn`。上涨绝大部分来自价格，而不是净扩张。
- 中国政策交易篮子进一步降至约 `4.4%`；平台科技约 `36.0%`，半导体/AI 扩至约 `36.9%`。风险预算明显从中国互联网与韩国 ETF 迁到存储、代工、设备、算力云和美国平台。
- 最强正向动作是新进 `AAPL PUT / BA / AAL / CRWV`，加仓 `META +54.6% / TSM +24.3% / UBER +21.5% / AMZN +15.7% / BIDU +87.1%`；但 `MU` -41.4%、`BABA` -42.3%，方向并不是全面加风险。
- 按“可抄作业 / 趋势跟踪”口径，Q2 最值得先看的是 `BA / AAL` 航空修复和 `CRWV` 算力云新仓；`AMZN / TSM / META / UBER` 是旧主线加码，`MU` 虽仍第二大却属于卖出侧。
- 2025Q1 的 `SPY PUT` 约占 `30.0%`，是全页最重要的反叙事信号：Appaloosa 可以一边持有高 beta 多头，一边用指数 put 表达系统性风险。
- 当前 filer 是 `Appaloosa LP` CIK `0001656456`；历史 `APPALOOSA MANAGEMENT LP` CIK `0001006438` 不混接。这个边界不写清，整条趋势就会变成伪连续。

## 数据口径

- 数据来自 SEC 13F information table，窗口为 `2022Q4` 到最新季度；正文展示 `2023Q1` 起，`2022Q4` 只用于计算第一季变化。
- 主动变化沿用机构页口径：已有仓位按 `(本季股数 - 上季股数) × 上季隐含价格` 估算，新进按本季市值，清仓按上季市值负数。
- 新进/退出前十大按“是否进入或离开前十大”计算；显著加减仓按股数/份额变化计算；权重变化只作为结果，不直接等同于主动交易。
- PUT/CALL、ETF 和普通股票分开读；13F 看不到完整期权结构、空头、现金、非美资产和季度内交易路径。

## 用 Appaloosa 方法重新读

### 1. 政策反应函数优先于静态标签

Tepper 的典型优势不是“永远喜欢某类资产”，而是判断政策、流动性和仓位结构什么时候改变了赔率。`BABA / PDD / JD / KWEB / FXI` 在 2024 变重，和他公开谈中国刺激政策能对上；后续减仓则提醒我们，这条线更像政策触发后的动态交易，而不是永久中国多头宣言。

### 2. 工具本身就是方法

`SPY PUT`、`AAPL PUT`、`KWEB / FXI / EWY` 这些不是页面噪音。对 Appaloosa 这类机构，ETF 和期权就是把宏观判断压成仓位的语言。忽略工具，只读普通股票名单，会把它读成完全不同的机构。

### 3. 高机动不等于没有主线

从 2023Q1 到最新季度，`AMZN / GOOG / META / UBER / NVDA / MU / TSM / VST / NRG` 反复出现，说明科技、半导体和现实电力约束是连续观察线。但 Appaloosa 的连续性不是低换手持有，而是主题在不同承接腿之间迁移。

### 4. 单季动作默认先读作交易

对 Appaloosa，单季前十大变化不能直接升格为长期 投资论点。只有当同一主题连续多季保留、扩大，且和公开政策/流动性判断能互相解释，才值得提高权重。否则，漂亮叙事会把你骗进后视镜。
