## 数据口径

- 展示2023Q1起的季度，保留2022Q4基期；原始申报、修订、封面值、逐行值和SHA256独立归档。日期按报告期归属，不按上传日期误归季度。
- CUSIP与证券类别识别股份，PUT/CALL独立。ticker仅供展示；同股不同类别不合并股数，公司级讨论另行合并权重。
- 权重分母采用信息表全部标准化value加总，含期权对应标的名义值，并非机构净资产。ETF、ADR及期权不能等同普通股票；期权股数为对应标的股数，不是合约张数。
- 主动项＝（本季股数－已核实拆股调整后基期股数）×基期隐含价；新列示按本季值，退出按上季值。价格项补足剩余变化；首次列示与公司行动不自动等于二级市场买入。
- 价格项还可能包含分拆分派等公司行动造成的估值变化，不是纯市场涨跌或总回报；母公司分拆不调整其持股数。
- 股数项是机械端点估算，也可能含实物分派或重组获得的股份。例如Liberty分派的Live股份首次列示，不能解释为同金额的主动买入。
- 拆股核验覆盖研究候选、历史前十与相邻期隐含价异常的标的；尚未逐一核验的小仓位列在来源审计中，历史股数项仍需结合公司行动复核。
- 行情仅用于季末之后的价格过滤，写明价格日；获取失败为N/A，不补零。价格上涨不倒推加仓动机。
- 13F缺少现金、空头、绝大多数非美证券与完整衍生品；无法据此判断申赎、真实成交价或今天的持仓。
- 本季新列示Oracle、应用材料、Modine、PG&E。
- Q2苹果和伯克希尔B的PUT在Q3不再列示，不能写成卖出两家正股，也无法仅凭13F区分平仓与到期。
- SpaceX同CUSIP的申报隐含价与其他机构存在差异，保留Appaloosa原值；股数增长不全部认定为二级市场买入。

## 用机构方法重新读

结合政策、盈利修正和相对机会成本理解轮动。普通股票、韩国ETF和期权分开解释；季度股数变化说明公开行为，不能证明其宏观动机。

### 既有方法分析

以下保留此前的方法讨论；最新季度数字以本页重核数据为准。

### 1. 政策反应函数优先于静态标签

Tepper 的典型优势不是“永远喜欢某类资产”，而是判断政策、流动性和仓位结构什么时候改变了赔率。`BABA / PDD / JD / KWEB / FXI` 在 2024 变重，和他公开谈中国刺激政策能对上；后续减仓则提醒我们，这条线更像政策触发后的动态交易，而不是永久中国多头宣言。

### 2. 工具本身就是方法

`SPY PUT`、`AAPL PUT`、`KWEB / FXI / EWY` 这些不是页面噪音。对 Appaloosa 这类机构，ETF 和期权就是把宏观判断压成仓位的语言。忽略工具，只读普通股票名单，会把它读成完全不同的机构。

### 3. 高机动不等于没有主线

从 2023Q1 到最新季度，`AMZN / GOOG / META / UBER / NVDA / MU / TSM / VST / NRG` 反复出现，说明科技、半导体和现实电力约束是连续观察线。但 Appaloosa 的连续性不是低换手持有，而是主题在不同承接腿之间迁移。

### 4. 单季动作默认先读作交易

对 Appaloosa，单季前十大变化不能直接升格为长期 投资论点。只有当同一主题连续多季保留、扩大，且和公开政策/流动性判断能互相解释，才值得提高权重。否则，漂亮叙事会把你骗进后视镜。
