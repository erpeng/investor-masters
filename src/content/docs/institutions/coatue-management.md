## 机构简介

**为什么值得单独读**

Coatue 值得单独读，是因为它不是普通“科技基金”。它把公开市场、私募成长、venture、数据研究和行业网络放进同一个技术投资平台。13F 看到的是公开美股切片，但这个切片会不断暴露它如何沿技术变化迁移仓位。

**机构轮廓**

本页采用 SEC 13F 披露主体 `COATUE MANAGEMENT LLC`，CIK `0001135730`。Philippe Laffont 是最核心人物；Thomas Laffont 和 Coatue 平台的公开材料则帮助理解它如何把 AI、私募网络和公开市场串起来。

## 投资哲学（机构级）

**它默认世界是什么样的**

技术变化会不断改写利润池，但利润池不一定留在最显眼的应用层。Coatue 的公开组合从 `NVDA / META / AMD / AMZN / MSFT`，迁到 `TSM / GEV / LRCX / AMAT / AVGO / ETN / CEG`，说明它会沿着需求的实际约束往上游和基础设施移动。

**它偏好哪类机会**

第一类是平台和应用：`AMZN / META / GOOGL / MSFT / NFLX / SPOT / APP / RDDT`。第二类是 AI 基础设施和价值链瓶颈：`TSM / NVDA / AVGO / LRCX / AMAT / ASML / CRWV`。第三类是电力和数据中心现实资产：`GEV / CEG / ETN / VRT / EQIX`。

## 激励结构与文化

**时间保护机制**

公开资料不足以完整证明基金条款，但 Coatue 能同时持有私募和公开技术资产，说明它至少在组织上接受“技术变化的兑现路径跨越多个资本市场阶段”。

**奖励什么**

它奖励的是跨阶段信息优势：从私募网络看到技术方向，从公开市场验证资本开支和需求，从 13F 仓位表达哪些瓶颈开始真正可投资。

**压制什么**

它不奖励单一金句式科技叙事。Coatue 的 13F 变化提醒外部读者：AI 不是一个 ticker，而是一条会在模型、芯片、设备、电力、数据中心、软件和应用之间迁移的价值链。

## 机构传承

Coatue 的传承问题不应只问 Philippe Laffont 个人还能投多久，而要问公私一体平台、数据研究和行业网络是否真的制度化。如果这些信息网络能持续产生早期信号并映射到公开市场仓位，Coatue 就不只是一个人的科技判断；如果不能，它就会退化成高 beta 科技基金。
