这页只做一件事：把 Maverick Capital 从 `2023Q1` 到 `2026Q1` 的 13F 持仓变化按时间摊开，再用 Lee Ainslie / Maverick 的机构语言去解释：行业专家制、深度基本面研究、建设性公司关系，以及 多空 股票组合里的公开 long book。它只能代表美国公开证券多头切片，不等于 Maverick 完整多空组合。

## 结论先行

- Maverick 最新 Q1 2026 可见 13F 持仓 `241` 个，总市值约 `$8.67bn`，前 5 大占 `24.4%`，前 10 大占 `40.0%`；这不是集中 long-only 组合，而是分散行业研究 long book。
- Q1 2026 13F 总市值变化：从 `$9.32bn` 到 `$8.67bn`，下降 `-$0.65bn`（-6.9%）。粗拆：主动仓位变化 `-$0.12bn`，价格变化 `-$0.52bn`；主要由价格变化拖累。 对 Maverick，这只说明 long book 的可见市值变化，不能推出净敞口变化。
- 最新季度的主线是行业再排序：`ASML / NU / RTX / AGX` 进入前十，`GOOG / PM / COF / UNP` 退出前十。
- `AI/半导体硬件` 暴露约 `$1.61bn` / `18.6%`，仍是最大公开多头容器；但结构从单一 NVDA/MSFT beta，扩到 `TSM / ASML / AMAT` 这些制造和设备瓶颈。
- `工业/国防/电力` 暴露约 `$0.73bn` / `8.4%`，`RTX / AGX / LIN` 说明 long book 有一条更偏实物瓶颈和电力基建的线。
- 最容易误读的一点：Maverick 是 多空 机构，13F 完全看不到 short book；所以不能把某个 long 行业暴露直接读成净看多。

## 数据口径

- 数据来自 SEC 13F information table，窗口为 `2022Q4-2026Q1`；正文展示 `2023Q1-2026Q1`，`2022Q4` 只用于计算 `2023Q1` 主动变化。
- 主动变化沿用机构页口径：已有仓位按 `(本季股数 - 上季股数) × 上季隐含价格` 估算，新进按本季市值，清仓按上季市值负数。
- 13F 只覆盖美国公开股票多头及部分期权披露，不覆盖空头、非美持仓、完整衍生品、现金和基金申赎。
- 对 Maverick，最关键的是把 13F 当作 `long book 的可见样本`，不能把它读成净敞口或完整行业判断。

### 这条线怎么读

Maverick 不是 Pershing 式战役平台，也不是 Fundsmith 式低换手质量组合。它的公开语言更像 Tiger 式行业专家制：在每个行业里找到更可能赢的公司，同时用 short book 或低配表达相对判断。

所以最新季度不能简单写成“看多半导体、看空微软”。更精确的读法是：公开 long book 继续保留 AI/半导体硬件主线，同时把权重从部分平台/消费金融/铁路/烟草仓位，挪向 ASML、NU、RTX、AGX 这类更细的行业判断。

如果没有 short book，就不知道它在每个行业内部到底配了什么反向表达。这是 Maverick 页最重要的边界。

## 三、用 Maverick 的方法重新读

### 1. 先看行业专家线，不是先看热门主题

Maverick 的公开多头会自然落在热门主题里，但它的方法不是追主题，而是在行业里比较赢家和输家。`NVDA / TSM / ASML / AMAT` 应读成半导体链条的不同环节，而不是一个笼统 AI 仓。

### 2. Q1 2026 的核心是再排序

`ASML / NU / RTX / AGX` 进入前十，`GOOG / PM / COF / UNP` 退出前十，说明 long book 从平台、烟草、消费金融和铁路，转向半导体设备、拉美金融科技、国防航空和电力工程。它像是行业专家线的再平衡，而不是单一宏观押注。

### 3. MSFT 被减，不等于平台 投资论点 消失

`MSFT` 从前排明显降权，但 `AMZN` 仍在第二大，数字平台容器没有消失。更合理的判断是：平台内部的相对吸引力变了，而不是 Maverick 放弃平台资产。

### 4. NU 是需要单独追踪的非美消费金融线

`NU` Q1 2026 股数明显增加，说明拉美数字银行这条线仍被提升。但它的风险也不是简单成长股风险，而是信贷周期、获客成本、监管和本币宏观共同作用。

### 5. 13F 最大盲区是 short book

Maverick 的方法核心是 赢家 vs 输家。13F 只给 赢家 或 long candidates 的一侧，看不到它在哪些同行、供应链或替代品上做了反向表达。没有这半边，就不能判断净行业暴露。

### 反向复盘

- `GOOG / PM / COF / UNP`：退出前十，说明 Maverick 在平台、烟草、金融和铁路之间做了机会成本切换。
- `MSFT / TSM / GOOG / PM` 等显著减股后仍有上涨或稳定，不能把减仓简单写成看空；更可能是风险预算和相对赔率调整。
- 公开 long book 看不到 short book；Maverick 的“可抄”必须比长期多头更保守。

## 继续观察

- `ASML / TSM / AMAT / NVDA` 是否继续同时留在前十；这是半导体链条暴露是否扩散的关键。
- `NU` 是否继续加股；这决定金融科技线是短期调仓还是核心行业判断。
- `RTX / AGX / LIN` 是否继续留在前排；这决定工业、国防和电力工程是否成为新的实物瓶颈线。
- `MSFT / GOOG` 是否重新回到前十；这决定平台仓位是降权还是退出核心。
- 13F 总市值是否扩张不能单独解释净风险；必须等待公开材料或后续季度交叉验证。

## 不能确认的部分

- 13F 看不到 Maverick 的 short book，所以无法判断净行业敞口。
- 13F 看不到非美持仓、完整衍生品和现金；不能把这页当成完整组合。
- 13F 看不到行业内部 pair trade，例如同一行业 long A / short B 的真实结构。
- 单季进出前十不等于 投资论点 完成变化，需要至少两个季度验证。
