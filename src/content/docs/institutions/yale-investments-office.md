## 机构简介

Yale Investments Office 值得单独读，不是因为它是一家大基金，而是因为它把大学 endowment 的时间结构、使命约束、资产配置和外部管理人选择组合成了一套可识别的方法。它是 `耶鲁模式` 的制度载体。

如果 Berkshire 是永久资本 + 企业所有权，Yale Investments Office 是长期使命 + 资产配置 + manager network。它的核心不是选出某只股票，而是让一所大学的长期资本持续服务教学、研究和跨代公平。

## 投资哲学（机构级）

Yale Investments 的机构哲学可以压成三句话：

- 长期资本应该利用自己的时间结构，而不是模仿短钱。
- 流动性不是越多越好，关键是为真正需要的流动性付钱。
- 另类资产只有在治理、manager access 和能力都成立时才有意义。

这使 Yale Model 和简单 60/40 组合拉开距离，也和机械堆另类资产拉开距离。前者可能低估长期资金的自由度，后者可能高估普通机构选择优秀管理人的能力。

## 激励结构与文化

Yale Investments 的核心文化不是交易速度，而是长期关系和 manager selection。它需要内部团队能识别外部管理人的能力、人格、激励结构和容量约束，也需要大学治理层长期支持策略，不因短期相对表现而频繁摇摆。

这套文化奖励耐心、独立判断、对复杂资产的理解和对合作伙伴的长期信任；压制的是短期排名冲动、资产类别标签崇拜和不理解流动性风险的盲目配置。

本页不生成 13F 趋势。

## 机构传承

Swensen 去世后，Yale Investments 的传承问题不是“还能不能找到第二个 Swensen”，而是这套制度能否保住三个核心条件：

- 大学治理层继续允许长期资产配置承受短期波动。
- 内部团队继续拥有识别优秀外部管理人的能力。
- 外部 manager network 不被规模、竞争和流动性压力稀释。

如果这些条件仍成立，Yale Model 就不是一个人的风格，而是一套制度化能力。
