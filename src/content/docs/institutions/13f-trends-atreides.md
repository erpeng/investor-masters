## 结论先行

Atreides 的 13F 应按“集中成长选股 + 高频主题轮换 + 战术期权”来读，不能当作低换手长期多头。`2026Q2` 首次公开披露 SpaceX 与 Cerebras 后，普通股排名表面上被两只私有公司重写；真正可比的公开市场动作仍要看 `MU / ALAB / CIEN / CRDO / PANW / U / COHR / NVDA / AMZN / META / CRWV`。

- 可见申报总额从 `$5.00bn` 升至 `$14.34bn`：普通股 `$4.10bn -> $11.15bn`，PUT `$0.81bn -> $2.36bn`，CALL `$0.09bn -> $0.83bn`。这不是基金 AUM，也不能把期权名义额当实际资本。
- `SpaceX` `$4.67bn`、`Cerebras` `$0.69bn` 是首次公开披露，不等于 Q2 买入。剔除两项首次披露后，Q2 普通股可比切片约 `$5.79bn`；机械粗拆约为主动 `-$0.44bn`、价格 `+$2.13bn`。
- 最硬的正向信号：`PANW` +56.1%、`META` 正股与 1.20m CALL 同时新进、`CRWV` +162.2%，并新进 `APH / GTLB / CIFR` 等；`CRDO / CIEN / COHR / NVDA / AMZN` 基本保留。
- 最硬的反向信号：`ALAB` -63.8%、`U` -17.3%、`MU` -6.5%；清仓 `LITE / SATS / ZM / RKT`。Q1 最强仓 ALAB 被大幅兑现，说明高换手属性没有改变。
- `QQQ PUT` 从 1.40m 增至 3.20m，名义额升至 `$2.36bn`；同时 `META CALL` 与 `Cerebras CALL` 出现。结构是“扩大指数保护 + 选择性个股凸性”，不是单向风险偏好。

## 用 Atreides 的方法重新读

1. **先看股数，再看排名。** Q2 `MU` 减股却升至公开市场第一大；SpaceX/Cerebras 首次披露又机械稀释其他权重，排名比以往更容易误导。
2. **把期权当战术层。** QQQ PUT 会跨季度快速开关；同一标的也会同时持有普通股与 CALL。除非知道期限、执行价、delta 和组合外空头，不能从名义市值推净方向。
3. **双重确认比单一动作更强。** Q2 `META` 正股与 CALL 同向新进；`ALAB` 则大幅减股。前者是增量确认，后者是对 Q1 强信号的快速反转。
4. **组合主题不是静态标签。** 2023年消费/支付/软件、2024年半导体/网络、2025年存储/软件与期权覆盖不断切换；真正稳定的是“寻找高弹性变化，再快速重排风险预算”。
5. **首次披露不等于本季交易。** SpaceX/Cerebras 只能说明截至 Q2 末首次公开可见；在缺少历史披露时，不能给出买入季度。

这套“指数防守 + 个股凸性 + 普通股集中度”的读法，以及它和 Miller、Tepper、Tudor、Berkshire 等人的差异，参见 [期权作为仓位语言](/investor-masters/concepts/options-as-position-language/)。

- `CIEN / COHR / CRDO / NVDA / MU` 的股数方向是否重新一致；目前“价格/权重”与“主动动作”仍明显分裂。
- `QQQ PUT` 是否继续放大；其开关往往比单只股票更能提示组合风险预算。

## 不能确认的部分

- PUT/CALL 的执行价、到期日、买卖方向、delta 和对手盘。
- 公开普通股与私募投资、空头、现金、非美资产之间的净风险。
- 季度内是否先买后卖，以及13F报告日之后的任何动作。
- 组合市值变化是否来自基金申赎；本页的“主动/价格”只是持仓数学粗拆，不是审计后的损益归因。
- SpaceX/Cerebras 的历史持仓起点；本页只确认首次公开披露，不猜测建仓季度。
