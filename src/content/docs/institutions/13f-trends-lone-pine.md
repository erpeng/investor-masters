抓取时间：`2026-05-26 10:21 CST`。

这页只做一件事：把 Lone Pine Capital 从 `2023Q1` 到 `2026Q1` 的 13F 持仓变化按时间摊开，再用史蒂芬·曼德尔公开讲过的 `investing behind change` 去解释。读法重点不是把它写成“成长股组合”，而是看关键变化怎样从主题落到公司经营变量。

## 结论先行

- Lone Pine 是基本面多头/对冲型 老虎幼崽，13F 只能看到美国公开多头切片，看不到空头、非美资产和净敞口。最新 Q1 2026 可见 13F 有 `36` 个持仓，前 5 大合计 `29.6%`，前 10 大合计 `51.6%`。
- Q1 2026 13F 总市值变化：从 `$13.61bn` 到 `$12.54bn`，下降 `-$1.07bn`（-7.8%）。粗拆：主动仓位变化 `-$0.42bn`，价格变化 `-$0.64bn`；主要由价格变化拖累。
- 最新季度最重要的事实不是单纯减仓，而是承接层变化：`TSM / AVGO / MSFT / DASH / KKR` 退出前十大或明显下降，`CRS / APP / TLN / TER / NU / Medline` 进入前十。
- `AI/算力/电力约束` 在 Q1 2026 可见暴露约 `52.4%`；`金融/资本市场` 可见暴露约 `12.4%`。组合不是离开变化，而是在从一阶平台/半导体，迁到电力、测试、材料、工程、应用变现和新金融平台。
- 从 2023 到 2026，前排主线大致经历了 `软件/平台 + 半导体`、`平台科技 + 支付/旅游/消费服务`、`AI 电力约束 + 资本市场/金融资产`、再到 `电力/材料/测试/应用层` 的迁移。

## 数据口径

- 数据来自 SEC 13F information table，窗口为 `2022Q4-2026Q1`；正文展示 `2023Q1-2026Q1`，`2022Q4` 只用于计算 `2023Q1` 主动变化。
- 主动变化沿用机构页口径：已有仓位按 `(本季股数 - 上季股数) × 上季隐含价格` 估算，新进按本季市值，清仓按上季市值负数。
- 权重变化不直接等于加减仓；如果股数下降但权重上升，优先解释为价格或组合总市值变化影响。
- Lone Pine 是 多空 机构，13F 不展示空头、对冲、非美普通股、现金和组合净敞口；这里不能逆推出完整组合风险。

### 这条线怎么读

Lone Pine 的公开方法不是抽象主题投资。史蒂芬·曼德尔说的“顺着变化下注”，重点仍然要回到企业内部：变化会改写哪些经营变量、管理层是否能顺着变化执行、研究组织能否持续识别这些变化。

这让 Q1 2026 的动作很值得读：如果只看 `TSM / AVGO / MSFT` 下降，会误读成“撤出 AI”；但同时 `VST / ASML / CRS / TLN / TER / APP` 留在或进入前排，更像从一阶平台和半导体暴露，转向电力、材料、测试、工程、应用层变现这些下一层约束。

## 三、用 Lone Pine 的方法重新读

### 1. 变化不是主题，变化要落到经营变量

Lone Pine 的 13F 适合问：这家公司是不是处在真正会改变行业结果的变化里？`VST / TLN` 对应电力价格和数据中心负荷，`ASML / TER / TSM / AVGO` 对应半导体制造和测试，`APP` 对应移动广告模型和应用分发效率，`LPLA / BN / KKR / COF` 对应金融资产、资金成本和资本市场环境。

### 2. Q1 2026 不是简单减仓，而是承接层重排

`TSM / AVGO / MSFT / DASH / KKR` 的下降很明显，但同季 `CRS / APP / TLN / TER / NU / Medline` 进入前十。按 Lone Pine 的语言，这更像在比较哪一层变化更有经营兑现，而不是简单从成长股撤退。

### 3. Lone Pine 比质量长期持有者更机动

和 Fundsmith 或 Himalaya 不同，Lone Pine 的前十大更频繁重排。这里不能把单季买入当作长期所有者信号；更合适的读法是连续观察：进入前十以后是否继续加股，退出前十以后是否彻底清掉，主题是否连续三四季出现。

## 不能确认的部分

- 13F 不展示空头和对冲，所以无法判断 Lone Pine 的净多头、行业净敞口或真实风险预算。
- 13F 不覆盖非美普通股和私募/场外表达，不能等同于完整基金组合。
- 无法仅凭 13F 判断动作由资金流、估值纪律、单股 投资论点 变化还是团队内部组合再平衡驱动。
