## 数据口径

- 展示2023Q1起的季度，保留2022Q4基期；原始申报、修订、封面值、逐行值和SHA256独立归档。日期按报告期归属，不按上传日期误归季度。
- CUSIP与证券类别识别股份，PUT/CALL独立。ticker仅供展示；同股不同类别不合并股数，公司级讨论另行合并权重。
- 权重分母采用信息表全部标准化value加总，含期权对应标的名义值，并非机构净资产。ETF、ADR及期权不能等同普通股票；期权股数为对应标的股数，不是合约张数。
- 主动项＝（本季股数－已核实拆股调整后基期股数）×基期隐含价；新列示按本季值，退出按上季值。价格项补足剩余变化；首次列示与公司行动不自动等于二级市场买入。
- 价格项还可能包含分拆分派等公司行动造成的估值变化，不是纯市场涨跌或总回报；母公司分拆不调整其持股数。
- 股数项是机械端点估算，也可能含实物分派或重组获得的股份。例如Liberty分派的Live股份首次列示，不能解释为同金额的主动买入。
- 拆股核验覆盖研究候选、历史前十与相邻期隐含价异常的标的；尚未逐一核验的小仓位列在来源审计中，历史股数项仍需结合公司行动复核。
- 行情仅用于季末之后的价格过滤，写明价格日；获取失败为N/A，不补零。价格上涨不倒推加仓动机。
- 13F缺少现金、空头、绝大多数非美证券与完整衍生品；无法据此判断申赎、真实成交价或今天的持仓。
- AMZN和DHR成为前两大；V、TSM、GOOGL、MCK大比例增幅包含低基数效应。

- 芯片、生命科学与平台分别核查公司经营，不用行业标签代替验证。

## 用机构方法重新读

沿用investing behind change：先看变化发生在哪些公司经营变量，再看新承接是否持续。高换手不能自动证明宏观主题反转，公开多头也不等于净组合。

### 既有方法分析

以下保留此前的方法讨论；最新季度数字以本页重核数据为准。

### 1. 变化不是主题，变化要落到经营变量

Lone Pine 的 13F 适合问：这家公司是不是处在真正会改变行业结果的变化里？`VST / TLN` 对应电力价格和数据中心负荷，`ASML / TER / TSM / AVGO` 对应半导体制造和测试，`APP` 对应移动广告模型和应用分发效率，`LPLA / BN / KKR / COF` 对应金融资产、资金成本和资本市场环境。

### 2. Q1 2026 不是简单减仓，而是承接层重排

`TSM / AVGO / MSFT / DASH / KKR` 的下降很明显，但同季 `CRS / APP / TLN / TER / NU / Medline` 进入前十。按 Lone Pine 的语言，这更像在比较哪一层变化更有经营兑现，而不是简单从成长股撤退。

### 3. Lone Pine 比质量长期持有者更机动

和 Fundsmith 或 Himalaya 不同，Lone Pine 的前十大更频繁重排。这里不能把单季买入当作长期所有者信号；更合适的读法是连续观察：进入前十以后是否继续加股，退出前十以后是否彻底清掉，主题是否连续三四季出现。
