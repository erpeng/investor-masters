## 数据口径

- 展示2023Q1起的季度，保留2022Q4基期；原始申报、修订、封面值、逐行值和SHA256独立归档。日期按报告期归属，不按上传日期误归季度。
- CUSIP与证券类别识别股份，PUT/CALL独立。ticker仅供展示；同股不同类别不合并股数，公司级讨论另行合并权重。
- 权重分母采用信息表全部标准化value加总，含期权对应标的名义值，并非机构净资产。ETF、ADR及期权不能等同普通股票；期权股数为对应标的股数，不是合约张数。
- 主动项＝（本季股数－已核实拆股调整后基期股数）×基期隐含价；新列示按本季值，退出按上季值。价格项补足剩余变化；首次列示与公司行动不自动等于二级市场买入。
- 价格项还可能包含分拆分派等公司行动造成的估值变化，不是纯市场涨跌或总回报；母公司分拆不调整其持股数。
- 股数项是机械端点估算，也可能含实物分派或重组获得的股份。例如Liberty分派的Live股份首次列示，不能解释为同金额的主动买入。
- 拆股核验覆盖研究候选、历史前十与相邻期隐含价异常的标的；尚未逐一核验的小仓位列在来源审计中，历史股数项仍需结合公司行动复核。
- 行情仅用于季末之后的价格过滤，写明价格日；获取失败为N/A，不补零。价格上涨不倒推加仓动机。
- 13F缺少现金、空头、绝大多数非美证券与完整衍生品；无法据此判断申赎、真实成交价或今天的持仓。
- HWM股数不变；APP、FICO均增股但权重下降。
- BKNG和TW进入前十；V减股1.84%但权重上升。
- Kensico横向风格权重1.0为本季新增启发式，不追溯改写旧评分。
- NET Power权证原始期限写法不一致，保留独立类别，不并入普通股票榜。

### 既有方法分析

以下保留此前的方法讨论；最新季度数字以本页重核数据为准。

### 1. 低曝光不等于没方法

Kensico 的困难在于：它没有大量公开长访谈来解释自己的方法。所以这页不能写成“某位大师说了什么”，而要写成“组合连续做了什么”。从 2023Q1 到最新季度，`HWM / FICO / V / ICE / FI` 这组金融基础设施和工业瓶颈反复出现，说明 Kensico 的公开组合不是随机主题拼盘。

### 2. 赢家会改变组合形状

`APP` 从 2024 年进入前排，到 2025 年成为三成以上权重，是这条线最有价值的样本。读法不是简单说 Kensico 追 AI，而是看它是否允许一个被验证的赢家从小仓变成组合形状本身。这和 Fundsmith 式长期质量不同，也和 Appaloosa 式政策交易不同。

### 3. 质量骨架和高 beta 腿并存

`FICO / V / FI / ICE / TW` 是金融基础设施和交易/支付网络，`HWM` 是航空工业瓶颈，`GOOGL / AMZN / MSFT` 是平台科技。这种组合说明 Kensico 不是只在一个行业里押注，而是在多个可验证护城河和少数高弹性赢家之间做集中组合。

### 4. 外部跟踪的最大误读是后视镜叙事

如果只在 2025 年以后看到 `APP` 权重大，就很容易把 Kensico 写成 AI/广告平台基金。但 2023-2024 的骨架告诉我们，它原本更像基本面集中组合。`APP` 是赢家改变组合，不是组合一开始就只有一个主题。
