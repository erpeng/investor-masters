这页把 Kensico 的公开 13F 当作组合行为证据来读，而不是把它包装成访谈式方法论。Kensico 公开长访谈很少，所以最可靠的材料反而是：机构注册资料、SEC 13F、以及多季度持仓轨迹。

## 结论先行

- Kensico 不能按纯低换手质量组合读，也不能按宏观交易基金读。更准确的标签是 `低公开曝光 + 基本面集中组合 + 允许赢家改变组合形状`。
- 最新 Q1 2026 13F 总市值从 `$5.88bn` 到 `$4.90bn`，变化 `-$987.4m`；粗拆主动变化 `$193.3m`，价格变化 `-$1.18bn`。
- `APP` 是全页最重要的变量：最新权重 `26.7%`，展示窗口峰值 `35.7%`；`HWM` 最新权重 `23.9%`，构成第二条长期骨架。
- `HWM / FICO / V / ICE / FI / GOOGL / AMZN / MSFT` 反复出现，说明 Kensico 不是只押一个 AI/广告 beta，而是把金融基础设施、平台科技、航空工业瓶颈和能源/旅行资产放在同一个可见组合里。
- 最大风险是外部读者把 13F 当完整组合。13F 看不到现金、空头、非美资产、私有资产、完整衍生品和季度内交易路径。

## 数据口径

- 数据来自 SEC 13F information table，窗口为 `2022Q4` 到最新季度；正文展示 `2023Q1` 起，`2022Q4` 只用于计算第一季变化。
- 主动变化沿用机构页口径：已有仓位按 `(本季股数 - 上季股数) × 上季隐含价格` 估算，新进按本季市值，清仓按上季市值负数。
- 新进/退出前十大按“是否进入或离开前十大”计算；显著加减仓按股数/份额变化计算；权重变化只作为结果，不直接等同于主动交易。
- Kensico 披露里没有显著 ETF/PUT/CALL 工具，因此主要按普通股票组合读；但这不代表完整基金没有对冲。

## 用 Kensico 方法重新读

### 1. 低曝光不等于没方法

Kensico 的困难在于：它没有大量公开长访谈来解释自己的方法。所以这页不能写成“某位大师说了什么”，而要写成“组合连续做了什么”。从 2023Q1 到最新季度，`HWM / FICO / V / ICE / FI` 这组金融基础设施和工业瓶颈反复出现，说明 Kensico 的公开组合不是随机主题拼盘。

### 2. 赢家会改变组合形状

`APP` 从 2024 年进入前排，到 2025 年成为三成以上权重，是这条线最有价值的样本。读法不是简单说 Kensico 追 AI，而是看它是否允许一个被验证的赢家从小仓变成组合形状本身。这和 Fundsmith 式长期质量不同，也和 Appaloosa 式政策交易不同。

### 3. 质量骨架和高 beta 腿并存

`FICO / V / FI / ICE / TW` 是金融基础设施和交易/支付网络，`HWM` 是航空工业瓶颈，`GOOGL / AMZN / MSFT` 是平台科技。这种组合说明 Kensico 不是只在一个行业里押注，而是在多个可验证护城河和少数高弹性赢家之间做集中组合。

### 4. 外部跟踪的最大误读是后视镜叙事

如果只在 2025 年以后看到 `APP` 权重大，就很容易把 Kensico 写成 AI/广告平台基金。但 2023-2024 的骨架告诉我们，它原本更像基本面集中组合。`APP` 是赢家改变组合，不是组合一开始就只有一个主题。

- `APP` 股数是否继续上升，还是仅由价格决定权重变化。

- 外部读者不能把 `APP` 高权重直接等同于 Kensico 对 AI 或广告行业的完整 投资论点；它只能证明公开 13F 的仓位结果。
