## 逐季度解读

### 2026Q2

- 市场背景：本节只用季末持仓事实命名动作，不用季度后的涨跌倒推当时观点。
- 组合结构：从 `$1.26bn` 到 `$1.56bn`，变化 `$0.31bn`（+24.3%）；拆股调整后，主动仓位约 `$0.11bn`，价格贡献约 `$0.20bn`，价格变化是主因。
- 前十大变化：新进 `BKNG`；退出 `SUNB`。
- 主动增加：`BKNG` 股数 +330.4k / +80.4%（按 25:1 拆股调整）；`APP` 股数 +122.4k / +38.6%；`UBER` 股数 +671.7k / +61.6%；`SPGI` 股数 +93.7k / +42.1%；`META` 股数 +38.2k / +23.6%；`DHR` 股数 +46.0k / +7.9%。
- 主动减少：`SUNB` 股数 1.05m / -47.8%；`AER` 股数 356.7k / -31.7%；`ASML` 股数 9.9k / -7.1%。
- 一句话：按 moat、再投资跑道和资本配置读；长期质量并不排斥按机会成本主动换仓。


### 2026Q1

这是一次非常明显的组合换骨：Sunbelt、AppLovin、S&P Global、Uber 进入前十，Booking、AutoZone、Alphabet C、Enovis 退出前十。它更像 opportunity cost 重排，而不是低换手质量组合的自然漂移。

- 持仓总市值变化：从 `$1.15bn` 到 `$1.26bn`，上升 `$105m`（+9.2%）。粗拆：主动仓位变化 `$106m`，价格变化 `-$725,376`；主要由主动仓位变化推升。
- 显著加仓：SUNB、APP、SPGI、UBER。
- 显著减仓：AZO、GOOG、ENOV 清仓；DHR、ASML 明显减股。
- 方法解读：Dorsey 不是只守住既有 moat 标签，而是在重新比较 runway、估值和资本配置后的机会成本。

## 用 Dorsey 方法重新读

Dorsey 的 13F 给出两个同时成立的事实。

第一，集中是真的。大多数季度前十大接近或等于整个可见 13F，2026Q1 前十仍占 `94.5%`。这和官网 10-15 个集中全球股票策略一致。

第二，低换手不是真的，至少不能从 13F 这样写。2025Q1 以后，组合从 `SMAR / WIX / PYPL / SPT / HRI` 等平台/软件/设备租赁切片，转向 `ASML / DHR / AER / AZO / BKNG / RPRX / LYV`，2026Q1 又引入 `SUNB / APP / SPGI / UBER`。这说明 Dorsey 的“长期”并不是拒绝换仓，而是不断比较护城河、再投资 runway、资本配置与当前价格的 opportunity cost。
