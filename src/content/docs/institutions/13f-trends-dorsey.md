## 用 Dorsey 方法重新读

Dorsey 的 13F 给出两个同时成立的事实。

第一，集中是真的。大多数季度前十大接近或等于整个可见 13F，2026Q1 前十仍占 `94.5%`。这和官网 10-15 个集中全球股票策略一致。

第二，低换手不是真的，至少不能从 13F 这样写。2025Q1 以后，组合从 `SMAR / WIX / PYPL / SPT / HRI` 等平台/软件/设备租赁切片，转向 `ASML / DHR / AER / AZO / BKNG / RPRX / LYV`，2026Q1 又引入 `SUNB / APP / SPGI / UBER`。这说明 Dorsey 的“长期”并不是拒绝换仓，而是不断比较护城河、再投资 runway、资本配置与当前价格的 opportunity cost。

### 反向复盘

- `AZO / GOOG / ENOV / BKNG`：退出前十或清仓，说明 Dorsey 在重排 opportunity cost，而不是简单持有所有 moat 公司。
- `DHR / ASML`：仍在核心但明显减股；这类动作要连续看，不能只按“好公司被减仓”下结论。
- `APP` 曾在 2024Q3 出现后又消失，本季重新进入前四；需要下一季确认它是新核心还是高弹性机会。

## 继续观察

- `SUNB` 是否是新核心，还是 2026Q1 单季事件性进入前十。
- `APP` 是重新进入组合并成为前四，还是更短期的高弹性机会。
- `ASML / DHR / AER` 减股后是否仍是长期骨架。
- `RPRX / LYV / SPGI` 是否体现 Dorsey 对 royalty、现场娱乐、金融信息基础设施的 durable moat 判断。

## 不能确认的部分

- 不能确认现金、非美持仓、完整全球组合和客户申赎。
- 不能确认季度内交易路径。
- 不能用 13F 反推每个标的的完整 投资论点。
- 不能把 2026Q1 的 Sunbelt/AppLovin 读成永久核心，至少还需要后续季度验证。
