## 数据口径

- 展示2023Q1起的季度，保留2022Q4基期；原始申报、修订、封面值、逐行值和SHA256独立归档。日期按报告期归属，不按上传日期误归季度。
- CUSIP与证券类别识别股份，PUT/CALL独立。ticker仅供展示；同股不同类别不合并股数，公司级讨论另行合并权重。
- 权重分母采用信息表全部标准化value加总，含期权对应标的名义值，并非机构净资产。ETF、ADR及期权不能等同普通股票；期权股数为对应标的股数，不是合约张数。
- 主动项＝（本季股数－已核实拆股调整后基期股数）×基期隐含价；新列示按本季值，退出按上季值。价格项补足剩余变化；首次列示与公司行动不自动等于二级市场买入。
- 价格项还可能包含分拆分派等公司行动造成的估值变化，不是纯市场涨跌或总回报；母公司分拆不调整其持股数。
- 股数项是机械端点估算，也可能含实物分派或重组获得的股份。例如Liberty分派的Live股份首次列示，不能解释为同金额的主动买入。
- 拆股核验覆盖研究候选、历史前十与相邻期隐含价异常的标的；尚未逐一核验的小仓位列在来源审计中，历史股数项仍需结合公司行动复核。
- 行情仅用于季末之后的价格过滤，写明价格日；获取失败为N/A，不补零。价格上涨不倒推加仓动机。
- 13F缺少现金、空头、绝大多数非美证券与完整衍生品；无法据此判断申赎、真实成交价或今天的持仓。
- 238条原始记录按稳定证券身份及管理人记录聚合；同证券重复管理记录相加，正股与期权独立。
- META上季仅有很小仓位，本季为大幅增股而非首次列示；百分比受极小基数放大。
- Alphabet两类股在轨迹中独立、横向评分先公司级净额；不能同时把GOOG买入和GOOGL卖出当作两家公司的信号。

## 用机构方法重新读

以可实现内在价值、管理层资本配置和价格折让研究组合。数据是Harris Associates L.P.全部申报范围，不等同于Oakmark单只基金，也不将全部交易归于某一基金经理。比较增持背后的验证问题与减持后的机会成本，避免把低估值标签当成经营证据。

### 既有方法分析

以下保留此前的方法讨论；最新季度数字以本页重核数据为准。

### 1. 它买的不是便宜，而是可实现的折价

Oakmark 的价值框架不是“PE 低就买”。它要买的是市场价格低于内在价值，而且内在价值能被时间、现金流和管理层行为逐步兑现。所以 `CRM / GOOGL / ICE / ABNB / IQV / SCHW / COF / COP` 要放在同一张问题表里看：折价在哪里？兑现机制是什么？管理层有没有帮股东把价值拿回来？

### 2. 减仓同样重要，因为它暴露“价值实现后的纪律”

`WBD / DE / PSX / COP / EOG` 的减仓不能机械读成看空，但它说明 Oakmark 在重新比较机会成本。价值投资里最大的问题不是买得便宜，而是价值实现以后还把它当成原来的便宜资产。

### 3. 新进前十比小幅权重变化更重要

`TRGP` 进入前十，比某个老仓位权重小幅变化更有信号。权重变化可能来自价格；进入前十通常意味着它在 Oakmark 的机会成本排序里上移。
