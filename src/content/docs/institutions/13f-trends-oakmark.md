这页把 Oakmark / Harris Associates 从 `2023Q1` 到 `2026Q1` 的 13F 持仓摊开。读法不是“低 PE 就是价值”，而是看它如何在可估值资产里做时间套利：哪些折价已经兑现，哪些折价还愿意继续等，哪些现代平台业务被纳入价值框架。

## 结论先行

按可实现折价和时间套利读；主动减仓既可能是价值兑现，也可能是实现路径变弱。

- 最新季度：`2026Q2` vs `2026Q1`；从 `$75.03bn` 到 `$75.42bn`，变化 `$0.39bn`（+0.5%）；拆股调整后，主动仓位约 `-$2.67bn`，价格贡献约 `$3.06bn`，主动仓位与价格方向相反。
- Q2 前十大：`KDP` 4.0%、`ABNB` 3.6%、`CRM` 3.4%、`IQV` 3.1%、`COF` 3.1%、`GOOGL` 3.0%、`SCHW` 3.0%、`ICE` 2.9%、`TRGP` 2.8%、`FCNCA` 2.5%；前五/前十集中度为 `17.1% / 31.4%`。
- 新进前十：`FCNCA`；退出前十：`COP`。进入前十只表示组合排名变化，是否主动买入仍看拆股调整后的股数。
- 主要主动增加：`Bank`、`MMC`、`SYY`、`Equitable`、`GOOG`、`BKNG`；主要主动减少：`PSX`、`BAC`、`Charter`、`WBD`、`MPC`、`GOOGL`。
- 本页将普通股动作与期权、ETF、票据等工具分开；最新判断仍以股数变化为主。

## 数据口径

- 数据来自 SEC 13F information table，窗口为 `2022Q4-2026Q2`；正文展示 `2023Q1-2026Q2`，`2022Q4` 只用于计算 `2023Q1` 主动变化。
- 主动变化以股数/份额为主，并对疑似拆股做了粗调整；权重变化只作为组合结果，不直接等于买卖动作。
- 13F 只覆盖美国公开股票多头及部分期权披露，不等于 Oakmark 完整基金组合，也看不到现金、非美本地持仓和不同基金之间的差异。
- 13F 里会出现 `PRN/NOTE` 这类可转债或票据披露；本页将它们与普通股拆开，例如 `NVST NOTE 1.750% 8/1` 不和 `NVST` 普通股合并。
- 对 Oakmark 这种价值型机构，单季减仓不必然代表 投资论点 失效；它可能是估值修复后的纪律兑现，也可能是价值实现路径变弱，需要连续看股数和前十大地位。

### 这条线怎么读

Oakmark 的 13F 不是简单的低估值清单，也不是短线交易清单。它更像一组“可解释折价”的外显切片：公司要足够便宜，但也要有能让价值回到明面上的路径，例如现金流改善、管理层资本配置、行业周期修复或市场重新理解商业模式。

Q1 2026 的主线不是简单防御，也不是重新押注传统价值。`CRM` 升到第一大，`TRGP` 进入前十，`GOOGL / ICE / KDP / ABNB / IQV / SCHW / COF` 仍在核心圈；同时 `WBD / DE / PSX / COP / EOG` 被明显修剪。这更像折价池内部从“修复已经走过一段的周期/媒体资产”转向“软件现金流、平台、交易所和中游能源”。

## 三、用 Oakmark 的方法重新读

### 1. 它买的不是便宜，而是可实现的折价

Oakmark 的价值框架不是“PE 低就买”。它要买的是市场价格低于内在价值，而且内在价值能被时间、现金流和管理层行为逐步兑现。所以 `CRM / GOOGL / ICE / ABNB / IQV / SCHW / COF / COP` 要放在同一张问题表里看：折价在哪里？兑现机制是什么？管理层有没有帮股东把价值拿回来？

### 2. 减仓同样重要，因为它暴露“价值实现后的纪律”

`WBD / DE / PSX / COP / EOG` 的减仓不能机械读成看空，但它说明 Oakmark 在重新比较机会成本。价值投资里最大的问题不是买得便宜，而是价值实现以后还把它当成原来的便宜资产。

### 3. 新进前十比小幅权重变化更重要

`TRGP` 进入前十，比某个老仓位权重小幅变化更有信号。权重变化可能来自价格；进入前十通常意味着它在 Oakmark 的机会成本排序里上移。
