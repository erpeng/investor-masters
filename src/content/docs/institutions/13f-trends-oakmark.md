这页把 Oakmark / Harris Associates 从 `2023Q1` 到 `2026Q1` 的 13F 持仓摊开。读法不是“低 PE 就是价值”，而是看它如何在可估值资产里做时间套利：哪些折价已经兑现，哪些折价还愿意继续等，哪些现代平台业务被纳入价值框架。

## 结论先行

- Oakmark 是主动价值型机构，不是指数增强，也不是纯低估值篮子。最新 Q1 2026 可见 13F 有 `152` 个持仓，前 5 大合计 `16.8%`，前 10 大合计 `30.8%`。
- Q1 2026 13F 总市值变化：从 `$79.12bn` 到 `$75.03bn`，下降 `-$4.09bn`（-5.2%）。粗拆：主动仓位变化 `$1.43bn`，价格变化 `-$5.52bn`；主要由价格变化拖累。
- 最新前十大是 `CRM / ICE / KDP / ABNB / GOOGL / COP / TRGP / IQV / SCHW / COF`。这不是单一科技组合，也不是传统金融能源组合，而是软件现金流、交易所、消费品牌、平台、能源和金融共同构成的“现代价值”篮子。
- Q1 2026 最值得看的变化是：`TRGP` 进入前十，`WBD` 退出前十；`CRM / NFLX / IT / ICLR / FI` 有明显股数加仓，`WBD / DE / PSX / COP / EOG` 有明显股数减仓。
- `现代价值/无形资产`、`金融与市场基础设施`、`能源与实物资产`、`消费/医疗防御`、`工业/周期再定价` 构成 Oakmark 当前可见折价池；Q1 2026 这些主题的可见暴露合计约 `56.7%`。
- 如果要抄 Oakmark 的作业，不能只看谁便宜。更重要的是看它的问题：市场为什么低估这家公司？价值实现靠什么发生？如果答案只是“估值低”，那不是 Oakmark 式时间套利，只是便宜陷阱候选。

## 数据口径

- 数据来自 SEC 13F information table，窗口为 `2022Q4-2026Q1`；正文展示 `2023Q1-2026Q1`，`2022Q4` 只用于计算 `2023Q1` 主动变化。
- 主动变化以股数/份额为主，并对疑似拆股做了粗调整；权重变化只作为组合结果，不直接等于买卖动作。
- 13F 只覆盖美国公开股票多头及部分期权披露，不等于 Oakmark 完整基金组合，也看不到现金、非美本地持仓和不同基金之间的差异。
- 13F 里会出现 `PRN/NOTE` 这类可转债或票据披露；本页将它们与普通股拆开，例如 `NVST NOTE 1.750% 8/1` 不和 `NVST` 普通股合并。
- 对 Oakmark 这种价值型机构，单季减仓不必然代表 投资论点 失效；它可能是估值修复后的纪律兑现，也可能是价值实现路径变弱，需要连续看股数和前十大地位。

### 这条线怎么读

Oakmark 的 13F 不是简单的低估值清单，也不是短线交易清单。它更像一组“可解释折价”的外显切片：公司要足够便宜，但也要有能让价值回到明面上的路径，例如现金流改善、管理层资本配置、行业周期修复或市场重新理解商业模式。

Q1 2026 的主线不是简单防御，也不是重新押注传统价值。`CRM` 升到第一大，`TRGP` 进入前十，`GOOGL / ICE / KDP / ABNB / IQV / SCHW / COF` 仍在核心圈；同时 `WBD / DE / PSX / COP / EOG` 被明显修剪。这更像折价池内部从“修复已经走过一段的周期/媒体资产”转向“软件现金流、平台、交易所和中游能源”。

## 三、用 Oakmark 的方法重新读

### 1. 它买的不是便宜，而是可实现的折价

Oakmark 的价值框架不是“PE 低就买”。它要买的是市场价格低于内在价值，而且内在价值能被时间、现金流和管理层行为逐步兑现。所以 `CRM / GOOGL / ICE / ABNB / IQV / SCHW / COF / COP` 要放在同一张问题表里看：折价在哪里？兑现机制是什么？管理层有没有帮股东把价值拿回来？

### 2. 减仓同样重要，因为它暴露“价值实现后的纪律”

`WBD / DE / PSX / COP / EOG` 的减仓不能机械读成看空，但它说明 Oakmark 在重新比较机会成本。价值投资里最大的问题不是买得便宜，而是价值实现以后还把它当成原来的便宜资产。

### 3. 新进前十比小幅权重变化更重要

`TRGP` 进入前十，比某个老仓位权重小幅变化更有信号。权重变化可能来自价格；进入前十通常意味着它在 Oakmark 的机会成本排序里上移。

- `GOOGL / ABNB / ICE / IQV` 是否继续稳定；这些资产代表 Oakmark 对无形资产和平台型业务的价值化接受程度。
- `WBD` 是否继续下降；如果连续退出，它说明债务去化和内容资产重估 投资论点 的优先级明显下移。
- `DE / PSX / COP / EOG` 的后续股数变化，要用来区分周期兑现和真正离场。

## 不能确认的部分

- 13F 不能还原 Oakmark 旗下不同基金的完整组合，也看不到现金、债券、非美本地持仓和内部基金差异。
- 13F 看不到申赎、完整成本价和管理层沟通，不能把 13F 缩表直接写成主动看空。
- Oakmark 的真正判断来自对内在价值和管理层资本配置的估计；13F 只能看到结果，看不到每个公司在内部估值模型里的折价幅度。
