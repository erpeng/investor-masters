这页只做一件事：把 Greenlight Capital 近年通过 DME Capital Management, LP 披露的 `2023Q1` 到 `2026Q1` 13F 持仓变化按时间摊开。读法重点不是寻找热门主线，而是看艾因霍恩式 `反动量 + forensic 多空` 如何在可见多头里表达为住宅、工业、资源、医疗监管和消费修复等具体错价。

## 结论先行

- Greenlight / DME 是经典基本面 多空 机构，13F 只能看到美国公开多头切片，看不到空头、黄金以外的宏观对冲、非美资产和净敞口。最新 Q1 2026 可见 13F 有 `45` 个持仓，前 5 大合计 `41.1%`，前 10 大合计 `57.1%`。
- Q1 2026 13F 总市值变化：从 `$2.85bn` 到 `$3.19bn`，上升 `$0.34bn`（+12.0%）。粗拆：主动仓位变化 `$0.30bn`，价格变化 `$0.04bn`；主要由主动仓位变化推升。
- 最新季度最重要的事实是可见多头扩张而不是撤退：`ACHC / VSCO / DHT / PENN / Versant Media` 进入前十，`GPK / CPRI / CNC / KD / TEVA` 退出前十，同时 `SNX / PTON / BKV / SHC` 这类修复或供应链资产明显增加。
- Q1 2026 可见暴露里，`住宅/利率敏感` 约 `28.1%`，`工程/工业/资源` 约 `20.3%`，`消费/媒体/博彩` 约 `15.6%`。这不是一张成长股表，而是一组不舒服资产的错价修复篮子。
- 从 2023 到 2026，Greenlight 的前排主线大致经历了 `住宅/能源/金融`、`资源/工业/黄金`、`包装/医疗/IT 服务特殊情况`，再到 `医疗监管 + 消费修复 + 媒体/博彩 + 公司特定转机` 的迁移。

## 数据口径

- 数据来自 SEC 13F information table，窗口为 `2022Q4-2026Q1`；正文展示 `2023Q1-2026Q1`，`2022Q4` 只用于计算 `2023Q1` 主动变化。
- Greenlight 历史段使用 Greenlight Capital Inc（CIK `1079114`），`2024Q1` 以后使用 DME Capital Management, LP（CIK `1489933`）；CIK 切换附近的跨季主动变化只能作近似观察。
- 主动变化沿用机构页口径：已有仓位按 `(本季股数 - 上季股数) × 上季隐含价格` 估算，新进按本季市值，清仓按上季市值负数。
- 权重变化不直接等于加减仓；如果股数下降但权重上升，优先解释为价格或组合总市值变化影响。
- 13F 不展示空头、完整衍生品、非美普通股、现金和净敞口；因此不能把这页读成完整 Greenlight 组合。

## 三、用 Greenlight 的方法重新读

### 1. 先问错价来自哪里

Greenlight 的核心不是“便宜”二字，而是便宜为什么存在。`GRBK` 要看利率和住房供需是否让市场低估土地/经营杠杆；`FLR / CNR / DHT / WFRD` 要看周期现金流是否被当成一次性；`ACHC / CNC / TEVA / SHC` 要看监管、诉讼和支付压力是否已被过度反映；`VSCO / PENN / PTON` 要看经营修复是否比市场预期更快。

### 2. Q1 2026 是公司特定修复增多

`GPK / CPRI / CNC / KD / TEVA` 退出前十，`ACHC / VSCO / DHT / PENN / Versant Media` 进入前十，同时 `SNX / PTON / BKV / SHC` 明显加股。这个组合动作更像在换一组特殊情况，而不是改变成某个宏观主题。

### 3. 不能把黄金和空头缺口忘掉

Greenlight 的公开材料一直强调 多空 和市场结构意识。13F 只能看到多头和部分工具，不能看到空头账本。因此 `GLD` 降低或升高只能说明这张可见表里的黄金工具变化，不能推断完整组合风险态度。

### 4. 最近一季可继续研究的排序

- 第一优先级：`GRBK`，长期第一大仓，决定这张 13F 的住宅和利率敏感骨架。
- 第二优先级：`ACHC / VSCO / PENN / PTON / SHC`，这组最能体现 Greenlight 对不舒服资产和经营修复的偏好。
- 第三优先级：`FLR / CNR / DHT / BKV / WFRD`，资源、工程和运输周期仍是可见多头的重要支柱。
- 稳定观察：`BHF / PCG / SNX`，分别对应利率/保险负债、公用事业监管回报和 IT 渠道周期。
- 反向复盘：`GPK / CPRI / CNC / KD / TEVA / GLD`，这些减仓或退出项需要检查是 投资论点 变化、估值修复完成，还是换到更好的特殊情况。

## 不能确认的部分

- 13F 不展示空头和完整对冲，所以无法判断 Greenlight 的净多头、行业净敞口或真实风险预算。
- 13F 不覆盖非美普通股、私募、场外衍生品和现金，不能等同于完整基金组合。
- 无法仅凭 13F 判断动作由资金流、估值纪律、单股 投资论点 变化还是组合风险预算驱动。
