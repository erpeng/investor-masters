## 数据口径

- 展示2023Q1起的季度，保留2022Q4基期；原始申报、修订、封面值、逐行值和SHA256独立归档。日期按报告期归属，不按上传日期误归季度。
- CUSIP与证券类别识别股份，PUT/CALL独立。ticker仅供展示；同股不同类别不合并股数，公司级讨论另行合并权重。
- 权重分母采用信息表全部标准化value加总，含期权对应标的名义值，并非机构净资产。ETF、ADR及期权不能等同普通股票；期权股数为对应标的股数，不是合约张数。
- 主动项＝（本季股数－已核实拆股调整后基期股数）×基期隐含价；新列示按本季值，退出按上季值。价格项补足剩余变化；首次列示与公司行动不自动等于二级市场买入。
- 价格项还可能包含分拆分派等公司行动造成的估值变化，不是纯市场涨跌或总回报；母公司分拆不调整其持股数。
- 股数项是机械端点估算，也可能含实物分派或重组获得的股份。例如Liberty分派的Live股份首次列示，不能解释为同金额的主动买入。
- 拆股核验覆盖研究候选、历史前十与相邻期隐含价异常的标的；尚未逐一核验的小仓位列在来源审计中，历史股数项仍需结合公司行动复核。
- 行情仅用于季末之后的价格过滤，写明价格日；获取失败为N/A，不补零。价格上涨不倒推加仓动机。
- 13F缺少现金、空头、绝大多数非美证券与完整衍生品；无法据此判断申赎、真实成交价或今天的持仓。
- 原PSCM（CIK1336528）2026Q2及Q3提交13F-NT；持仓由上市母公司Pershing Square Inc.（CIK2026053）披露，NT不代表清仓。

## 用机构方法重新读

先辨管理人、上市母公司、PSH与PSUS基金产品的不同口径，再研究集中持仓的经营假设与催化剂。2026Q2起跟随Pershing Square Inc.申报，并将NEW HOLDINGS补充合入原Q2；PS发行人股份单列。Uber仍是核心仓，但Q3股数略减，不写作本季加仓。

### 既有方法分析

以下保留此前的方法讨论；最新季度数字以本页重核数据为准。

### 1. 先问 投资论点 生命周期，而不是先问买了什么

Pershing 的核心不是“买便宜股票”，而是把少数公司变成可公开辩护、可跟踪、可复盘的 投资论点。一个仓位被移出核心圈，通常比一个小仓新进更重要。

### 2. Q2 2026 的主线是扩展 投资论点 圈

Q1 是 `MSFT / AMZN` 替代 Alphabet 的平台核心换挡；Q2 则进一步加入 `Visa / Mastercard / S&P Global / Netflix`，同时加大 `HHH / META / Uber / QSR`。这说明 Pershing 不再只在大平台内部换仓，而是扩展到支付、数据与订阅商业模式。

### 3. 旧战役没有完全消失

`BN / Howard Hughes Holdings / QSR` 仍在组合里，而且 HHH/QSR 加股，说明 Pershing 仍保留资产平台、地产/社区开发和消费特许经营这几条旧能力圈。新支付与数据仓不是替代旧方法，而是增加可复制的收费网络和信息基础设施。

### 4. 关联载体与小仓要单列

`Pershing Square USA` 是关联载体，`Hertz / Seaport` 是小仓特殊情况；三者都不能和外部公司核心 投资论点 混为一谈。真正的新主战场是四个近十亿美元级新仓。

### 5. 最关键的反面检查

如果 `Visa / Mastercard / S&P Global / Netflix` 只是一次性组合扩张，而非长期核心，那么 Q2 的分散化意义会大幅下降。后续要看四个新仓是否继续留在前十一，同时检验 AMZN 减仓是否是估值管理还是 投资论点 降级。
