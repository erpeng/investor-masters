这页把 Baillie Gifford 从 `2023Q1` 到 `2026Q2` 的 13F 持仓摊开。读法不是“谁涨就买谁”，而是看这家长期成长机构如何在超级赢家池里做再排序：哪些公司还在核心，哪些被修剪，哪些新候选进入前十。

## 结论先行

- Baillie Gifford 是长期成长/超级赢家型机构。最新 Q2 2026 按 CUSIP 聚合后有 `273` 个可见持仓，前 5 大合计 `29.4%`，前 10 大合计 `44.7%`。
- Q2 2026 13F 总市值从 `$97.89bn` 升至 `$110.23bn`，增加 `$12.33bn`（+12.6%）。机械粗拆为主动变化 `+$5.47bn`、价格变化 `+$6.87bn`，但主动项包含 SpaceX 首次进入13F披露，不能等同为当季现金买入。
- `SpaceX` 首次出现在这条13F序列，披露市值约 `$8.78bn`、占 `8.0%`，直接成为第一大；由于此前未在13F中披露，只能确认“首次披露”，不能仅凭13F断言Q2新建仓。
- 其余前十大仍由 `NVDA / AMZN / MELI / SE / SPOT / NET / APP / SHOP / NU` 构成；`PDD` 退出前十但仍持有。核心平台普遍小幅减股，真正的主动升级集中在 `QXO / RY / CRH / AVGO / AXON` 等第二梯队。
- Baillie 没有简单从成长主轴撤退，但候选池继续分化：一边加入或放大前沿航天、建筑材料、银行和半导体基础设施，一边显著削减 `CPNG / NFLX / RKLB / META / MSFT / TEAM`。
- 如果要抄作业，不能只抄 Baillie 的名字单。更重要的是抄它的问题：这家公司有没有机会在 5-10 年里从高不确定性穿越到幂律赢家？如果没有，这张 13F 只是一张高波动成长股清单。

## 数据口径

- 数据来自 SEC 13F information table，窗口为 `2022Q4-2026Q2`；正文展示 `2023Q1-2026Q2`，`2022Q4` 只用于计算 `2023Q1` 主动变化。
- 主动变化以股数/份额为主，并对疑似拆股做了粗调整；权重变化只作为组合结果，不直接等于买卖动作。
- 13F 只覆盖申报清单内的证券，不等于 Baillie Gifford 完整全球组合。Q2 文件首次包含 SpaceX，但仍看不到多数未上市资产、非美本地持仓、现金和完整对冲。
- 对 Baillie 这种长期成长机构，单季减仓不必然代表 投资论点 失效；但退出前十、连续减股和主题暴露迁移需要认真复盘。

### 这条线怎么读

Baillie 的 13F 不是低估值猎手清单，也不是季度交易清单。它更像一个“长期成长概率分布”的外显切片：少数公司要承担大部分上行，很多公司只是候选，失败和回撤本来就在模型里。

Q2 2026 的最大变化是 SpaceX 首次进入13F披露并成为第一大，但这不能自动解释为当季新买入。剔除这一披露口径变化，原核心平台大多减股，新增主动信号更多来自 `QXO / RY / CRH / AVGO / AXON`；Baillie 正在把候选池从一阶成长赢家扩展到航天、建筑材料、金融和半导体基础设施。

## 三、用 Baillie 的方法重新读

### 1. 它买的不是平均成长，而是幂律分布

Baillie 的核心信念是：长期回报不是平均公司贡献的，而是少数超级赢家决定的。所以 `NVDA / MELI / AMZN / SHOP / SPOT / NET / SE / PDD` 这些名字要放在同一张问题表里看：谁还能继续扩大终局市场，谁只是估值修复后的普通成长股？

### 2. 减仓同样重要，因为它暴露“候选池淘汰”

`CPNG / NFLX / RKLB / META / MSFT / TEAM` 的减仓不能机械读成看空，但它说明 Baillie 在重新比较机会成本。对成长投资来说，最大错误不是卖飞一只好公司，而是把资金长期锁在已经失去非线性上限的公司里。

### 3. 首次披露不必然等于首次买入

SpaceX 在 Q2 首次出现在13F并成为第一大，是重要披露变化，但不能仅凭 Q1 缺席就断言 Baillie 在 Q2 买入全部 51,397,806 股。对这类此前不在13F切片里的资产，页面只记录“首次披露”和申报估值。

## 继续观察

- SpaceX 后续是否继续出现在13F、股份和申报估值如何变化；第一季披露不能单独形成交易轨迹。
- `QXO / RY / CRH / AVGO / AXON` 是否连续加股；它们是本季更有增量的信息。
- `NVDA` 的小幅加股能否延续，以及原平台核心的普遍减股是否停止。
- `CPNG / NFLX / RKLB / META / MSFT / TEAM` 是否连续下降；连续减仓才更接近候选池淘汰。

## 不能确认的部分

- 13F 不能还原 Baillie 的完整全球组合，尤其无法覆盖苏格兰抵押信托里的非美和未上市资产。
- 13F 看不到基金申赎、完整现金比例和内部基金之间的交叉配置，不能把 13F 缩表直接写成主动看空。
- Baillie 的真正判断来自长周期研究和组织文化；13F 只能看到结果，看不到每个公司在内部候选池里的概率权重。
