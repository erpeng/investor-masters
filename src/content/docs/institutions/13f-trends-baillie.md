这页把 Baillie Gifford 从 `2023Q1` 到 `2026Q1` 的 13F 持仓摊开。读法不是“谁涨就买谁”，而是看这家长期成长机构如何在超级赢家池里做再排序：哪些公司还在核心，哪些被修剪，哪些新候选进入前十。

## 结论先行

- Baillie Gifford 是长期成长/超级赢家型机构。最新 Q1 2026 可见 13F 有 `269` 个持仓，前 5 大合计 `26.6%`，前 10 大合计 `42.5%`。
- Q1 2026 13F 总市值变化：从 `$120.34bn` 到 `$97.89bn`，下降 `-$22.45bn`（-18.7%）。粗拆：主动仓位变化 `-$6.06bn`，价格变化 `-$16.38bn`；主要由价格变化拖累。
- 最新前十大仍是 `NVDA / AMZN / MELI / SPOT / NU / SHOP / NET / SE / PDD / APP`，说明它没有从成长主轴撤退；更准确的说法是：价格回撤中保留 AI 和全球平台核心，同时修剪部分成熟平台与广告链资产。
- Q1 2026 最值得看的变化是：`NET` 进入前十，`NFLX` 退出前十；`MMYT / AXON / BAP / APP / IOT` 有明显股数加仓，`TTD / MSFT / CPNG / NVDA / NFLX` 有明显股数减仓。
- `AI/算力与基础设施`、`电商/市场/全球平台`、`内容/广告/消费互联网`、`金融科技/新兴市场`、`生命科学/前沿医疗` 构成 Baillie 当前可见成长池；Q1 2026 这些主题的可见暴露合计约 `70.0%`。
- 如果要抄作业，不能只抄 Baillie 的名字单。更重要的是抄它的问题：这家公司有没有机会在 5-10 年里从高不确定性穿越到幂律赢家？如果没有，这张 13F 只是一张高波动成长股清单。

## 数据口径

- 数据来自 SEC 13F information table，窗口为 `2022Q4-2026Q1`；正文展示 `2023Q1-2026Q1`，`2022Q4` 只用于计算 `2023Q1` 主动变化。
- 主动变化以股数/份额为主，并对疑似拆股做了粗调整；权重变化只作为组合结果，不直接等于买卖动作。
- 13F 只覆盖美国公开股票多头及部分期权披露，不等于 Baillie Gifford 完整全球组合，也看不到 SpaceX、未上市资产和多数非美本地持仓。
- 对 Baillie 这种长期成长机构，单季减仓不必然代表 投资论点 失效；但退出前十、连续减股和主题暴露迁移需要认真复盘。

### 这条线怎么读

Baillie 的 13F 不是低估值猎手清单，也不是季度交易清单。它更像一个“长期成长概率分布”的外显切片：少数公司要承担大部分上行，很多公司只是候选，失败和回撤本来就在模型里。

Q1 2026 的主线不是撤离 AI 或撤离成长。`NVDA` 仍是第一大，`NET` 进入前十，`AMZN / MELI / SPOT / NU / SHOP / SE / PDD / APP` 仍在核心圈；但 `TTD / MSFT / CPNG / NFLX` 被明显修剪。这更像成长池内部从“已经验证的一批”向“下一批候选和区域平台”再排序。

## 三、用 Baillie 的方法重新读

### 1. 它买的不是平均成长，而是幂律分布

Baillie 的核心信念是：长期回报不是平均公司贡献的，而是少数超级赢家决定的。所以 `NVDA / MELI / AMZN / SHOP / SPOT / NET / SE / PDD` 这些名字要放在同一张问题表里看：谁还能继续扩大终局市场，谁只是估值修复后的普通成长股？

### 2. 减仓同样重要，因为它暴露“候选池淘汰”

`TTD / CPNG / MSFT / NFLX` 的减仓不能机械读成看空，但它说明 Baillie 在重新比较机会成本。对成长投资来说，最大错误不是卖飞一只好公司，而是把资金长期锁在已经失去非线性上限的公司里。

### 3. 新进前十比小幅权重变化更重要

`NET` 进入前十，比 `NVDA` 权重小幅上升更有信号。后者可能有价格因素；前者更像 Baillie 把 Cloudflare 放进了更核心的成长观察层。

### 反向复盘

- `NFLX / TTD / MSFT / CPNG`：显著减股或退出，说明 Baillie 在成熟平台和广告链上做机会成本切换。

- 下跌的 `NU / PDD / MELI` 不是自动更便宜，必须先确认本地监管、信贷、竞争和汇率没有破坏长期 runway。

## 继续观察

- Q2 2026 `NET` 是否继续留在前十；如果连续保留，它就是 Baillie 当前最值得跟踪的新核心候选。
- `NVDA` 是继续保持第一大，还是进入连续减股；这决定 Baillie 对 AI 算力瓶颈的信心是否开始降温。
- `MMYT / AXON / IOT / BAP` 是否继续加股；这些小到中等仓位更像下一批候选，而不是已经验证的核心赢家。
- `TTD / CPNG / NFLX` 是否继续下降；连续退出会说明它们在 Baillie 的超级赢家排序里下移。
- 非美和未上市资产仍要另看：SpaceX、美团、MiniMax 等不会完整体现在这张 13F 表里。

## 不能确认的部分

- 13F 不能还原 Baillie 的完整全球组合，尤其无法覆盖苏格兰抵押信托里的非美和未上市资产。
- 13F 看不到基金申赎、完整现金比例和内部基金之间的交叉配置，不能把 13F 缩表直接写成主动看空。
- Baillie 的真正判断来自长周期研究和组织文化；13F 只能看到结果，看不到每个公司在内部候选池里的概率权重。
