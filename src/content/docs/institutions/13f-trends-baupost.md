## 结论先行

- Baupost 最新 Q2 2026 可见 13F 持仓 `23` 个，总市值约 `$5.42bn`，前 5 大占 `49.9%`，前 10 大占 `74.9%`。
- Q2 2026 13F 总市值从 `$5.12bn` 升至 `$5.42bn`，增加 `$0.30bn`（+5.9%）。粗拆：主动仓位变化约 `-$0.27bn`、价格变化约 `+$0.57bn`；表面扩表主要来自价格，组合内部仍在净减仓。
- `AMZN` 再加股 20.0%，占比升至 16.5%；`GPC` 加股 89.0%并进入前十，`GOOG` 加股 16.2%，`CME` 新建可见仓位，构成最新的正向动作。
- 反向动作同样强：`WTW / VAXX` 清仓，`WCC` -53.9%、`QSR` -16.4%、`UNP` -23.1%、`EXP` -40.5%。Baupost 不是全面加风险，而是在公开股切片里继续压缩旧机会、集中到更少的现金流和催化剂问题。
- 最容易误读的一点仍然没变：Baupost 的 优势来源 往往在 13F 之外，尤其是现金、债务、不良资产、私有交易和跨资产机会；所以这页只能读公开股票切片的边际变化。

## 数据口径

- 数据来自 SEC 13F information table，窗口为 `2022Q4-2026Q2`；正文展示 `2023Q1-2026Q2`，`2022Q4` 只用于计算 `2023Q1` 主动变化。
- 主动变化沿用机构页口径：已有仓位按 `(本季股数 - 上季股数) × 上季隐含价格` 估算，新进按本季市值，清仓按上季市值负数。
- 13F 只覆盖美国公开股票多头及部分期权披露，不覆盖现金、债券、不良资产、非美资产、私有交易、空头和基金申赎。
- 对 Baupost，13F 不是组合全景，而是一张公开股票机会清单。读法重点是：哪些公开股票被提升为更高优先级，哪些特殊情况被移出前十。

### 这条线怎么读

Baupost 的 13F 最不能按“股票基金持仓榜”读。卡拉曼的公开方法强调安全边际、逆向纪律、耐心资本 和跨资产比较；公开股票只是机会容器之一。

Q2 2026 的公开股切片继续集中到可解释现金流：`AMZN` 再加股并升至 16.5%，`GPC / GOOG` 被明显加仓，`CME` 新进；与此同时 `WTW / VAXX` 清仓、`WCC / QSR / UNP` 大幅减股。它不是全面增加股票风险，而是在同一切片里提高少数机会的相对优先级。

这不是“Baupost 变成成长股基金”。更合适的读法是：在公开股票里，它把更多权重给了可长期解释的现金流平台，同时仍保留多个价值/特殊机会容器。

## 三、用 Baupost 的方法重新读

### 1. 先看风险收益比，不是先看公司名字

`AMZN / GOOG / V / AON / FERG` 这些名字看起来质量不错，但在 Baupost 语境里，关键不是它们是不是好公司，而是当时价格、风险、下行保护和替代机会是否给出足够 margin of safety。

### 2. 公开股票只是机会容器

Baupost 的历史气质是高现金、逆向和跨资产比较。13F 看不到现金和困境资产，所以如果只看公开股，会低估它等待和切换资产类别的能力。

### 3. Q2 2026 的主线是 AMZN 延续与 GPC 升级

`AMZN` 在 Q1 大幅加仓后，Q2 又增加 20.0%，成为连续两个季度最明确的平台现金流信号；`GPC` 股数增加 89.0%并进入前十，则把机会集扩展到零部件分销和维修后市场。

### 4. 金融基础设施重新变重要

`CME` 新进约 `$0.14bn`，`V` 保持股数不变，而 `WTW` 清仓、`AON` 减股。金融基础设施仍重要，但内部排序从保险经纪转向交易所与支付网络。

### 5. 特殊情况在收缩，但没有消失

`WTW / VAXX` 清仓，`LBTYK` 继续减股，同时出现小仓位 `AXTA / PSH`。特殊情况没有消失，但容器在快速轮换；很多真正的特殊机会仍不在13F里。

### 反向复盘

- `WTW / VAXX`：本季清仓；对Baupost而言，退出公开股切片是明确的机会成本信号。
- `WCC / QSR / UNP / EXP / LBTYK`：均显著减股；其中部分权重仍高，不能把“还在前十”误写成继续加仓。
- `ELV` 股数不变但权重升至第二，这是价格和其他仓位变化造成的组合结果，不是主动增持。

## 继续观察

- `AMZN` 是否第三个季度继续加股；连续性决定它是否成为更稳定的公开股核心。
- `GPC / GOOG / CME / NCLH` 是否继续加仓；这些是Q2更有增量的新问题。
- `WCC / QSR / UNP / LBTYK` 的减股是否延续，以及 `WTW` 清仓后风险中介暴露如何重排。
- 总市值变化仍需拆成主动与价格；公开股之外的现金、债和特殊机会无法由13F确认。

## 不能确认的部分

- 13F 看不到 Baupost 的现金比例。对 Baupost 来说，这是非常关键的信息缺口。
- 13F 看不到债券、不良资产、房地产、私有交易和完整空头；不能把公开股票切片当成完整组合。
- 13F 看不到基金申赎和成本基础，不能确认每次减仓背后的资金流和真实收益。
- 单季加仓不能自动解释为卡拉曼公开观点变化，需要后续季度和公开材料验证。
