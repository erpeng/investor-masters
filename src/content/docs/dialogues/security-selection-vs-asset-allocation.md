## 问题

大多数投资人天然把 alpha 想成“选对公司”。但 [大卫·史文森](/investor-masters/investors/david-swensen/) 提醒另一种长期收益来源：资产配置、负债端、流动性预算和 manager selection 本身也能形成优势。

## A：选股收益

选股收益默认价值来自理解具体企业：商业模式、护城河、管理层、再投资跑道、估值和资本配置。巴菲特、芒格、李录、Terry Smith、Rochon、Dorsey 都在这一侧。

它的优势是机制具体，错误更容易回到公司层复盘。

## B：资产配置收益

资产配置收益默认优势来自资金结构和制度结构：你是否有长钱、能否承受非流动性、能否找到优秀外部管理人、能否在多资产之间长期再平衡。

Swensen / Yale Model 是这一侧的核心样本。

## 真正张力

选股收益争夺的是公司理解深度；资产配置收益争夺的是时间结构和组织能力。

前者问“这家公司值不值得拥有”；后者问“这笔资本的使命、期限和能力结构允许它拥有什么”。

## 什么时候选股收益胜

当投资者能深入理解少数公司、拥有稳定资本、并能承受公司级波动时，选股收益胜。

## 什么时候资产配置收益胜

当资本规模巨大、使命长期、需要跨代稳定支出、且具备 manager access 和治理耐心时，资产配置收益胜。

## 可迁移工具

先不要问“该买什么”，先问“我这笔钱是什么钱”：

1. 期限多长？
2. 现金流需求多强？
3. 能承受多大不流动性？
4. 有没有能力识别外部管理人？
5. 治理层能不能忍受长期策略短期落后？

这五个问题答不出来，谈耶鲁模式基本都是装饰。
