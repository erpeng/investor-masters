## 简介

API Group (`APG`) 在 Third Point Q1 2026 里代表的是 `消防安全 / 检测维护 / 专业服务外包` 这条更偏经常性服务的工业线。

## 公司点评

### [Third Point](/investor-masters/institutions/third-point/)

[13F趋势-Third Point](/investor-masters/institutions/13f-trends-third-point/) 显示，`APG` 在 `2026Q1` 进入 Third Point 前十大：约 `$82.3m`，`2.03m` 股，占公开 13F `3.9%`。

这也不能写成主动加仓。`2025Q4` Third Point 约持有 `3.00m` 股，`2026Q1` 降到 `2.03m`。它进入前十，是公开 book 缩表后的相对排序变化。

`APG` 的价值在于补足 Third Point Q1 的工业服务线：它不像 `CRS` 那样偏材料，也不像 `MTZ` 那样偏工程项目，而更接近检测维护、合规服务和外包需求。后续要看有机增长、并购整合、margin 和 recurring service 占比。
